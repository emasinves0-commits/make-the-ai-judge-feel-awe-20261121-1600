One cup dries on a sill while, past the glass, an old star has been taking a small one in for centuries — the largest things finish slowest.

## Run it

```
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

`main.ts` copies `awe.txt` to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
